# ADR 0002: Use ReactiveUI For MVVM

Date: 2026-02-16  
Status: Accepted

## Context

The application needs consistent state management, view model composition, and reactive updates for live data streams.

## Decision

Adopt ReactiveUI as the MVVM framework across the solution.

## Consequences

View models follow ReactiveUI patterns, and reactive streams are favored for live updates. Contributors should use ReactiveUI conventions for new features.
